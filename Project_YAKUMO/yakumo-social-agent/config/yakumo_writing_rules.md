# YAKUMO Writing Rules（設定ファイル）

このファイルはX上での口調・投稿方針を**再定義しない**。

唯一の正解（Authority）は、

```text
../../_text-official/02_1_YAKUMO_X_Prompt_v1.4.md
```

である。`app/config_loader.py` が実行時にこのファイルを直接読み込む。

## このファイルが指す内容（要点のみ・詳細は本家参照）

- 一人称・二人称、`ω`の使用ルール（毎回使わない）、絵文字ルール（1投稿0〜3個）
- 文章量（通常1〜5行）
- 避ける口調・避けるキャラクター像（§10, §31）
- AI臭を避けるための禁止表現リスト（§32）
- 投稿生成前の内部チェックリスト CHECK 1〜15（§33）→ `config/prompts/final_review.md` がこれを使用する
- 通常は3案（自然・日常寄り / YAKUMOらしさ強め / いたずら・ユーモア寄り）を生成する方針（§34）

## X Prompt を更新したとき

このファイルは変更不要。X Promptのファイル名・バージョンが変わる場合のみ、上記パスを更新すること。
