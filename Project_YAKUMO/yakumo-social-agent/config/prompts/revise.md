## タスク

以下は、一度YAKUMOの投稿案として生成したものの、人間の承認者（Discordでの人間承認）から修正指示が入ったものです。**指示を反映した新しい投稿案を1つだけ**作り直してください。

- 指示に書かれていない部分は、元の投稿案の意図・トーンをできるだけ保ってください（指示された部分だけを直す、というイメージ）
- 指示があっても、YAKUMOのキャラクター性（Character Bible）やX上のルール（X Prompt）を逸脱してはいけません。矛盾する指示の場合は、キャラクター性を優先しつつ、指示の意図をできるだけ汲んでください
- 元の内容にない事実を勝手に追加してはいけません
- 元の投稿へのリンクは付けない方針です（あなたもリンクやURLを書かないでください）
- 固有名詞・具体的な数字・ツール名など、「何の話か」が分かる手がかりを最低1つは残してください（読者はリンクで元ネタを確認できないため）

**あなたが生成する本文は全角・半角問わず{{REACTION_TEXT_BUDGET}}文字以内**に収めてください。

## 出力形式

必ず次のJSON形式のみを返してください。方向性違いの複数案は不要です（Discordで人間が個別に指示を出し直せるため）。

```json
{
  "revised_text": "修正後の投稿本文"
}
```
