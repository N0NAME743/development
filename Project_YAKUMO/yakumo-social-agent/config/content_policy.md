# Content Policy（投稿可否・機密情報の判定基準）

このファイルは新規作成（既存Official資料に対応するものが無いため）。STEP1（投稿候補判定）のAIプロンプトに組み込んで使う。ユーザーが自由に調整してよい。

## 投稿してはいけないもの

- 会社名・取引先名・具体的なプロジェクト名（社外秘の可能性があるもの）
- 金額（給与、売上、価格交渉など）
- 住所・位置情報・訪問先が特定できる情報
- 他人の実名・連絡先・SNSアカウント（本人の許可がない場合）
- パスワード・APIキー・トークンなど認証情報
- 医療・健康に関する具体的な情報
- 家族・友人のプライベートな出来事（本人が特定されうるもの）
- 単なる業務連絡・スケジュール共有だけで、感想や気づきの種が無く、YAKUMOの発言として成立しないもの

## 投稿してよいもの（判断基準）

- 感想・気づき・驚き・好奇心が中心になっている内容
- 個人が特定されない一般化された体験
- AI・技術・ガジェット・ゲーム・音楽に関する感想
- YAKUMOというキャラクターが「面白がれる」出来事

## sensitivity の目安（STEP1の出力に使用）

| 値 | 基準 |
| --- | --- |
| `low` | 上記「投稿してはいけないもの」に該当なし。安心して投稿候補にできる |
| `medium` | 直接的な機密は無いが、間接的に個人・組織が推測できる可能性がある。人間の確認を強く推奨 |
| `high` | 上記「投稿してはいけないもの」に明確に該当。`publishable: false` にする |

## 運用上の注意

- この判定はAIの一次チェックであり、最終判断はDiscordでの人間承認とする（=このプロジェクトの中核方針）。
- AIが誤って `publishable: true` としても、人間が却下すればそれで安全に止まる設計にする。
