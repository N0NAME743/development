# claude_skill_lab

Agent Skill や GitHub リポジトリを安全に試すための実験環境です。
本番のプロジェクトとは切り離し、ここで自由に検証・実験を行います。

## フォルダ構成

### `skills/`
自作または入手した Agent Skill（`SKILL.md` を含むスキル定義一式）を配置します。
新しいスキルを試作したり、他所で見つけたスキルを取り込んで動作確認する場所です。

### `repos/`
動作確認したい GitHub リポジトリを `git clone` してくる場所です。
外部リポジトリのコードを実行・検証する際は、まずここに隔離した状態で試します。

### `workspace/`
上記スキルやリポジトリを使って実際に手を動かす作業スペースです。
検証用のスクリプトや一時ファイル、試行錯誤の成果物などを置きます。

## 運用方針

- 各フォルダは実験用の使い捨てとして扱ってよく、不要になったものは適宜削除して構いません。
- 外部から取得したコードやスキルは、内容を確認してから実行してください。
