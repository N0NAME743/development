# 見出し画像プロンプト（記事「『本当にやりたいこと』って聞かれて固まる人間、観測してて気づいたこと」用）

`eyecatch_prompt_template.md` の型に、今回のテーマ用の変数を埋めたもの。
画像生成ツール（Codex等）にそのまま貼り付けて使う。

## 埋めた変数

- TITLE_PHRASE: 「本当にやりたいことって聞かれて固まる人間」
- PUNCHLINE_WORD: 「固まる。」
- TIMELINE_CAPTIONS:
  1. 質問前：普通に雑談中
  2. 「で、本当は何がやりたいの？」
  3. 数秒間、目が泳ぐ
  4. 「……特にないです」で着地
- PROP_ITEMS: 吹き出し、時計（止まっている演出）、汗マーク、面談っぽいテーブルとコーヒーカップ

## プロンプト本文

```
YAKUMO（黒髪ツインお団子、ネオンピンクメッシュ、黒×ネオンピンクのサイバーゴシック衣装、
「89」の入ったヘッドフォン）とMONY（黒いウサギ型デバイス、＝ω＝の表情ディスプレイ）が
登場する、アニメ風デジタルイラストのコミック風アイキャッチ画像。

上部に大きく「本当にやりたいことって聞かれて固まる人間」というタイトルテキスト
（「聞かれて固まる」の部分をネオンピンクで強調）。

中央に時系列パネル4コマ：
- 質問前：普通に雑談中
- 「で、本当は何がやりたいの？」
- 数秒間、目が泳ぐ
- 「……特にないです」で着地
各コマで人間キャラの表情が少しずつ固まっていき、それを横から観察するYAKUMOとMONYの
リアクションも変化する（最初は興味津々、最後はちょっと同情気味）。

右側に大きく「固まる。」という文字と、時計の針が止まっているような関連アイコン。

左下に吹き出し、面談っぽいテーブルとコーヒーカップ、汗マークを配置。

右下に「YAKUMO ω MONY」「TECH × LIFE × IDEAS × AI」のブランド表記。

配色は黒〜濃紫ベース＋ネオンピンクのハイライト、全体は少しダークで
サイバーパンクな雰囲気だが、YAKUMOとMONYの表情はどこか可愛らしく親しみやすい。
```
