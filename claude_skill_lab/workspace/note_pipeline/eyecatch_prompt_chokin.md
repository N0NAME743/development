# 見出し画像プロンプト（記事「貯金が増えない人間、だいたい同じところで詰んでる」用）

`eyecatch_prompt_template.md` の型に、今回のテーマ用の変数を埋めたもの。
画像生成ツール（Codex等）にそのまま貼り付けて使う。

## 埋めた変数

- TITLE_PHRASE: 「貯金が増えない人間、だいたい同じところで詰んでる」
- PUNCHLINE_WORD: 「消えてる。」
- TIMELINE_CAPTIONS:
  1. 給料日：よし今月こそ貯金する
  2. 第1週：コンビニでちょっとずつ
  3. 第3週：サブスクが引き落とされてる（気づいてない）
  4. 月末：通帳を見て真顔
- PROP_ITEMS: レシート、財布、通帳、貯金箱

## プロンプト本文

```
YAKUMO（黒髪ツインお団子、ネオンピンクメッシュ、黒×ネオンピンクのサイバーゴシック衣装、
「89」の入ったヘッドフォン）とMONY（黒いウサギ型デバイス、＝ω＝の表情ディスプレイ）が
登場する、アニメ風デジタルイラストのコミック風アイキャッチ画像。

上部に大きく「貯金が増えない人間、だいたい同じところで詰んでる」というタイトルテキスト
（「貯金が増えない」の部分をネオンピンクで強調）。

中央に時系列パネル4コマ：
- 給料日：よし今月こそ貯金する
- 第1週：コンビニでちょっとずつ
- 第3週：サブスクが引き落とされてる（気づいてない）
- 月末：通帳を見て真顔
各コマでYAKUMOの表情・状況が少しずつ変化していく（最初は自信満々、最後は放心気味）。

右側に大きく「消えてる。」という文字と、財布から小銭がこぼれ落ちるような関連アイコン。

左下にレシート・財布・通帳・貯金箱を配置。

右下に「YAKUMO ω MONY」「TECH × LIFE × IDEAS × AI」のブランド表記。

配色は黒〜濃紫ベース＋ネオンピンクのハイライト、全体は少しダークで
サイバーパンクな雰囲気だが、YAKUMOとMONYの表情はどこか可愛らしく親しみやすい。
```
