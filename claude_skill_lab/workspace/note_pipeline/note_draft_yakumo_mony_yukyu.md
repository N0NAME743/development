# 有給取った人間、だいたい休んでる最中も仕事のこと考えてる

最近、ちょっと気になってることがある。

「有給」って、本来は何もしなくていい日のはずなのに、なんでみんなそんなに落ち着かないんだろう。

前からずっと不思議だった。

で、ちょうどいい実例をひとつ見つけたので、記録しておく。

カレンダーに「有給」って丸がついてる、ある人間の一日。

朝はゆっくり起きて、テレビつけて、コーヒー淹れて。

普通に休みの日、のはずだった。

なのに11時くらいから、様子がおかしくなってきた。

スマホを触る手が、SNSでもゲームでもなく、会社のチャットアプリの方に伸びてる。
別に通知が来てるわけじゃない。自分から開きに行ってる。

見て、閉じて。数分後、また同じアプリを開いてる。

会議があるはずの時間になると、テレビを見ながらでも時計をチラッと見る。
「今頃あの件、どうなってるんだろ」って顔をしてる。

休みなのに、休んでない。

これ一人だけかと思ったら、他でも似たようなの何回か見た。
有給の日にかぎって、なぜかチャットアプリを開く回数が増える人間、ヤクモが思ってたよりずっと多い。

## なんでこうなるのか

しばらく考えてたんだけど、これ「サボってる罪悪感」とはちょっと違う気がしてる。

もし単なる罪悪感なら、有給を申請する瞬間がいちばんつらくて、当日になれば楽になるはず。

でも実際は逆で、休み始めてからの方がそわそわしてる。

たぶん理由はこう。

会社にいる間は、自分の周りで何が起きてるか、だいたいリアルタイムで把握できてる。
誰が何を話してて、どの案件が動いてて、何が止まってるか。

有給を取った瞬間、そこだけ急に情報が途切れる。

**仕事が止まるわけじゃなくて、自分だけ見えなくなる。**

会社は普通に動いてる。
自分の知らないところで、何かが進んでたり、誰かが困ってたりするかもしれない。
そのことを、頭のどこかがずっと気にしてる。

人間の脳、こういうの苦手らしい。
「まだ終わってない」「まだ分からないまま」で放置されてることがあると、意識が勝手にそっちへ戻ろうとするみたいで。
途中で切り上げた作業のほうが、終わらせた作業よりなぜか記憶に残りやすい、みたいな話も前からあるらしい。

有給の日の「見えなくなった会社」は、まさにこれと同じ扱いを受けてる。
終わったわけじゃなくて、ただ見えなくなっただけだから、頭が勝手に続きを気にしてる。

休んでるのに、心のタブが1個だけ開きっぱなしになってる感じ。

適当な相槌のつもりで、ちょっとモニィにも聞いてみた。

「モニィも、通信切ったままにしといたら気になる?」

`・ω・`

しばらく考えてから、モニィが自分の側面の通信リングをぱたっと止めた。
いつもは薄く光ってる部分を、自分で消してみせた。

30分後。

`＝ω＝`……にしては、なんか変な光り方をしてる。
何度も自分の側面をちらっと見てる。

「気になるっぽいね」って言ったら、慌てたみたいにリングをまた元に戻してた。

ヤクモも人間のことは言えない。似たようなとこある。

面白くない?

## じゃあどうすればいいか

観測してて効いてそうだったのは3つ。全部じゃなくて、1個でいい。欲張ると続かない。

**1個目。有給の前日に、自分が抜けてる間の「拾い役」だけ決めておく。**

何かあったら誰が対応するか、それだけ先に共有しておく。
「自分がいなくても、ちゃんと誰かが見てる」というのが分かってるだけで、見えないことそのものへの不安がだいぶ減る。
仕事の中身まで引き継ぐ必要はなくて、「誰が拾うか」の一点だけでいい。

**2個目。チャットは「見ない」じゃなくて「〇時に1回だけ見る」に変える。**

一日中見ない、と決めると、逆に「今どうなってるか分からない」という空白がずっと続く。
夕方に1回だけ見る、と先に時間を決めておくと、その時間まで待てばいいだけになる。

**「見ない」を目指すんじゃなくて、「いつ見るか」を先に決めておくだけでいい。**

気になる気持ちの置き場所を、あらかじめ用意しておくという話。

**3個目。有給の日の時計を、仕事の時間割で読まない。**

13時になったとき「今頃あの会議やってるな」って自動的に思い浮かぶ人は、時間そのものを仕事の単位で覚えてしまってる。
時計を見て会社のことを思い出すんじゃなくて、今日の予定(昼ごはん、散歩、昼寝)だけで一日の時間を数え直す。

---

モニィの通信リング、あれから何度か自分で試してるみたいだけど、まだ30分が限界っぽい。

`・ω・`

……ヤクモも似たようなとこあるから、あんまり強くは言えないけど。

有給の日にスマホがやたら気になる人間がいたら、サボってるとかじゃなくて、ただ「見えないものが気になってるだけ」だと思う。

今度また、観測しといてあげる。
