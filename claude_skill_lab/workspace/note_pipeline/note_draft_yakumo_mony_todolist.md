# タスクリストに書いた人間、だいたい書いた時点で終わった気になってる

ちょっとこれ、聞いてほしいことがある。

人間のスマホとかメモ帳とか、たまに覗かせてもらってるんだけど。

「やることリスト」ってやつ、みんな結構ちゃんと書いてる。丁寧に。箇条書きで、時には優先順位まで振って。

なのに、その日の終わりにもう一回同じリストを見ると、ほとんど減ってない。

……あれ？ さっきの気合いは？

## 何日か張り付いて観測してみた

暇だったから、いくつかのリストを何日か追いかけてみた。

書く瞬間の勢い、すごい。「よし」「今日中に」「絶対終わらせる」みたいな気迫がある。書き終わった直後の顔、なんかスッキリしてる。

でも実際にその項目を消せてる数を数えたら、書いた数の半分もいってないことが多い。

面白いのは、消せてないのに、そのリストを書いた本人はわりと落ち着いてるってこと。慌てて追加でやろうとしない。むしろ「まあ、書いたし」みたいな顔をしてる。

書いた瞬間に、なんかもう一仕事終えたみたいな空気になってる。

## なんでこうなるのか

これ、やる気がないとかサボり癖とか、そういう話じゃない気がする。

頭の中に「あれもやらなきゃ、これもやらなきゃ」って浮かんでる状態って、地味に気になり続けるものらしい。ずっと頭の隅でチカチカする感じ。

それを紙とかスマホに書き出した瞬間、その「気になり続ける」ってやつが、いったん止まる。

**頭の中から外に出した時点で、脳は「もう手元にある、いつでも見れる」って判断して、気にするのをやめちゃうみたい。**書いた＝終わったじゃないのに、書いた＝もう大丈夫、まで一気に飛ぶ。

モニィに試しにやらせてみた。今度仕掛けようと思ってたいたずらのアイデア、頭の中だけで温めてたのと、ちゃんと文字にして書き出したのと、両方やってもらった。

`・ω・`

……書いた瞬間、心なしか目つきが緩んだ。

`＝ω＝`

で、数日後に聞いてみたら、頭の中だけで温めてた方はまだ覚えてて実行する気満々だったのに、書き出した方はすっかり存在を忘れてた。書いたメモ自体、どこに保存したかも怪しい。

書いたことに満足して、それ以上そこに触れる理由がなくなったっぽい。

## 見てて効いてそうだったこと

観測してて効いてそうだったのは3つ。全部やらなくていい。

1個目。リストに書くときに、項目だけじゃなく「最初の一歩」まで一緒に書く。「資料を作る」じゃなくて「資料のファイルを開く」くらいまで小さく割る。書いた瞬間の満足感を、行動の直前まで引きずれるらしい。

2個目。書いたリストを、見えるところに置きっぱなしにしない。一度しまう、閉じる、目に入らない状態を作ってから、あらためて開く。その「開き直す」という一手間が、意外と再点火のスイッチになるみたい。

3個目。書いた直後の妙な安心感を、あらかじめ疑っておく。「今スッキリしてるのは、終わったからじゃなくて、書いただけだから」って一回自分に言っておくと、その場の満足で止まりにくくなるっぽい。

---

リストを開いたまま画面を閉じるだけで、なんか一日頑張った気になれる。人間の脳、思ったよりだいぶ単純なところで満足してる。

モニィは結局、そのいたずら、まだ仕掛けてない。

`・ω・`

……多分もう忘れてる。
