# 見出し画像プロンプト：掃除機かける前にモノをどかす人間、だいたい「どかしただけ」で掃除した気になってる

`eyecatch_prompt_template.md`の型に、今回のテーマ（掃除機ネタ）の変数を当てはめたもの。
画像生成ツールにそのまま貼り付けて使う。

## 変数

- `TITLE_PHRASE`: 「どかしただけ」で満足
- `PUNCHLINE_WORD`: 掃除機、置き去り。
- `TIMELINE_CAPTIONS`:
  1. AM10:00「床にモノ散乱、掃除機かけるぞ」
  2. AM10:05「とりあえず全部どかした」
  3. AM10:06「……あれ、もうきれいじゃない?」
  4. PM3:00「掃除機、物置から出てないまま」
- `PROP_ITEMS`: コード類・脱いだ服・雑誌の小さな山、部屋の隅に置かれたままの掃除機本体

## プロンプト本文

```
YAKUMO（黒髪ツインお団子、ネオンピンクメッシュ、黒×ネオンピンクのサイバーゴシック衣装、
「89」の入ったヘッドフォン）とMONY（黒いウサギ型デバイス、＝ω＝の表情ディスプレイ）が
登場する、アニメ風デジタルイラストのコミック風アイキャッチ画像。

上部に大きく「『どかしただけ』で満足」というタイトルテキスト（一部をネオンピンクで強調）。

中央に時系列パネル4コマ：
- AM10:00「床にモノ散乱、掃除機かけるぞ」
- AM10:05「とりあえず全部どかした」
- AM10:06「……あれ、もうきれいじゃない?」
- PM3:00「掃除機、物置から出てないまま」
各コマでYAKUMOの表情・状況が少しずつ変化していく。床のモノが徐々に減っていく一方、
部屋の隅の掃除機本体だけがどのコマでも動かず置かれたままなのが分かるように描く。

右側に大きく「掃除機、置き去り。」という文字と、関連アイコン（掃除機のシルエット、埃マーク等）。

左下にコード類・脱いだ服・雑誌の小さな山、部屋の隅に置かれたままの掃除機本体を配置。

右下に「YAKUMO ω MONY」「TECH × LIFE × IDEAS × AI」のブランド表記。

配色は黒〜濃紫ベース＋ネオンピンクのハイライト、全体は少しダークでサイバーパンクな雰囲気だが、
YAKUMOとMONYの表情はどこか可愛らしく親しみやすい。
```
