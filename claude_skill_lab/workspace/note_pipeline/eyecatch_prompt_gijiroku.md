# 見出し画像プロンプト：記事#16「会議で議事録を書いてる人間、だいたい一番何も喋ってない」

`eyecatch_prompt_template.md`の変数を、このテーマ用に埋めたもの。
以下のプロンプト本文をそのまま画像生成ツール（Codex等）に貼り付けて使う。

## 変数の中身

- `TITLE_PHRASE`: 「議事録を書いてる人間、だいたい一番喋ってない」
- `PUNCHLINE_WORD`: 「無言。」
- `TIMELINE_CAPTIONS`:
  1. 「会議開始 — にこやかにメモを取り始める」
  2. 「議論が白熱 — キーボードを叩き続ける」
  3. 「『どう思う?』と聞かれる — 固まる」
  4. 「会議終了 — 誰よりも内容を正確に覚えている」
- `PROP_ITEMS`: ノートPC、付箋、ボールペン、湯気の立つマグカップ

```
YAKUMO（黒髪ツインお団子、ネオンピンクメッシュ、黒×ネオンピンクのサイバーゴシック衣装、
```
