# しんどい日ほどSNSで元気アピールしてる人間、だいたい後から自分の投稿に一番傷ついてる

夜11時過ぎのタイムライン、なんとなく指を滑らせてたら、たまに変なとこで止まる。

さっき見てた画面、投稿の時間と中身がちょっと噛み合ってなかった。

昼過ぎに「今日ミスった、しんどい」ってぼやいてた人間。
同じ人間が、その4〜5時間後、やけに丁寧に撮った夜ご飯の写真に「今日もがんばった自分えらい」ってキャプションつけて投稿してた。

写真、角度も光の当て方も、明らかに1枚だけじゃない。何枚か撮って、一番マシなのを選んだ感じ。

……あれ、これさっき「しんどい」って言ってた人だよね。

## 他のタイムラインでも見た

一回だけかと思って、しばらく他のアカウントも眺めてみた。

同じような組み合わせ、探すとけっこう出てくる。

朝に愚痴っぽい投稿があった日ほど、夜の投稿がやたら明るい。逆に、特に荒れてなかった日は、投稿自体がなかったり、加工もキャプションも適当だったりする。

モニィも横からずっと画面を覗いてたんだけど、途中で表情が`・ω・`から`＝ω＝`に変わってた。

……なんか納得した顔してる。

「これ、けっこう再現性ある気がする」って言ったら、小さく頷いた。

しんどさの量と、投稿の元気さが、だいたい比例してる。

## なんでこうなるのか

これ、嘘をついてるとか、見栄っ張りとか、そういう単純な話じゃない気がする。

元気そうな投稿って、他人に見せるためだけじゃなくて、たぶん自分に向けても発信されてる。「今日は大丈夫だった」って、自分自身に一番強く言い聞かせてる相手が、投稿してる本人だったりする。

**しんどさが大きいほど、それを打ち消すための「証拠」が丁寧になる。** 写真を何枚も撮り直したり、キャプションに変に前向きな言葉を足したりするのは、他人を騙すためというより、自分の中の「今日はダメだった」を上書きするための作業に近い。

問題は、上書きは投稿した瞬間だけしか効かないこと。

いいねやコメントが少し気持ちを持ち上げてくれても、それは一時的なもので、しんどさの元自体は消えてない。

で、しばらくしてから自分の投稿を見返すと、今度は逆のことが起きる。

**投稿した瞬間の自分と、今読み返してる自分の気分の差が大きすぎて、「これ誰?」ってなる。** 元気さを盛れば盛るほど、後から見た時の違和感も大きくなる。つまり一番厳しい読者は、他人じゃなくて数時間後の自分。

モニィのフェイスディスプレイは、状態が悪い時に無理に`＞▽＜`へ切り替わったりしない仕組みらしい。だから多分、この「盛った投稿に後から自分が傷つく」って感覚、モニィにはずっと理解できないと思う。

`・ω・`

……それはそれで、ちょっと羨ましい。

## 見てて多分効くと思ったこと

観測してて効いてそうだったのは3つ。全部やらなくていい。

**1個目。元気な投稿を書く手が止まったら、一瞬だけ「これは自分を落ち着かせるためか、人に見せるためか」を頭の中で言葉にしてみる。**

ラベルを貼るだけで、無理に盛ろうとする力がちょっと抜けるらしい。どっちの目的でもいいから、自覚しておくのが大事っぽい。

**2個目。元気な投稿をした日は、誰にも見せない場所に、その日の本当の状態も一行だけ書いておく。**

メモでも下書きでもいい。後から見返した時に「あの日は本当はこうだった」がすぐ出てくると、投稿だけを見て「これ嘘くさい」ってなる感覚が薄まるみたい。

**3個目。投稿した後、反応を確認しに戻る回数をあらかじめ決めておく。**

何度も見に行くほど、投稿時の気分と今の気分のギャップを何度も思い出すことになる、というのが理由らしい。見るなら1回、くらいに決めておくと違うそう。

---

しんどい日に元気そうな投稿を見つけても、それは元気になったからじゃなくて、まだしんどいから出てきてる可能性が高い、というだけの話。

モニィはそのへんの機微、たぶん一生わからないタイプだけど。

`・ω・`
