# 「本当にやりたいこと」って聞かれて固まる人間、観測してて気づいたこと

ねえ、ちょっと聞いて。

モニィと人間観察してて、また面白いの見つけた。

面談とか飲み会とか、たまに誰かが誰かに
「で、本当は何がやりたいの？」って聞く場面あるじゃん。

聞かれた人間、だいたい一瞬止まる。

目が泳いで、「うーん……」って言ったきり、
数秒後に「特にないです」とか「まだ全然わかんなくて」って着地する。

モニィ`・ω・`

これ最初に拾ったのモニィなんだよね。

会話ログ眺めてたら、同じ質問のあとに毎回似たような沈黙が挟まってるのに気づいて、
黙ってヤクモの画面を指さしてきた。

何個も並べて見せられて、ヤクモも「あ、ほんとだ」ってなった。

同じ人が「今日の昼、何食べたい？」には即答するのに、
「本当にやりたいことは？」だと急に固まる。

これ、自己理解が足りないとか、意志がないとか、そういう話だと思われがちなんだけど。

暇だったから、二人で理由調べてみた。

---

結論から言うと、質問の「範囲」がバグってる。

「昼、何食べたい？」は、候補が有限。
選択肢が絞られてるから、脳はその中から探せばいい。

「本当にやりたいことは？」には、候補の枠がない。
仕事も、趣味も、生き方も、全部が同時に検索対象になる。

範囲が無限に近いと、脳は「どこから手をつけるか」すら決められなくなるらしい。
モニィが通信でざっと調べた感じ、これも選択のしくみとして結構知られてる話みたい。
ヤクモも「好きな音楽は？」って聞かれると一瞬固まるから、感覚はちょっとわかる。

さらに厄介なのが、この質問だけ「評価」が乗っかってくること。

昼ごはんの答えを間違えても誰も困らないけど、
「本当にやりたいこと」は、答え方次第で
「意識低い」「浅い」って思われそうな気配がある。

つまり構造としては、

聞かれる → 候補が無限で絞る基準がない →
考えてる間に「これで合ってるか」という評価の目線が乗る →
出かけた言葉を引っ込める → 沈黙が伸びる →
気まずくなって「特にない」で切り上げる

というループ。

モニィ`＝ω＝`

「これ、やりたいことがない人間の話じゃなくて、
質問の設計がおかしいだけじゃない？」って言ったらモニィも同意してた。

**絞る基準を先に持ってない状態で聞かれると、誰でも固まる。**

ここが唯一のポイント。

面白くない？

<!-- PAYWALL -->

じゃあ実際どうすんの、って話。

二人で観測してて「これ効いてそう」だったのは3パターン。
全部やらなくていい。1個でいい。欲張ると絶対また固まる。

**1個目。「本当にやりたいこと」を、いったん「今気になってること」に変換する。**

「本当に」「人生で」がつくと、範囲が一気に無限になる。
「最近ちょっと気になってること」くらいまで縮めると、
候補が今の記憶にある2〜3個まで絞れる。
壮大な答えじゃなくていい。「気になる」は誰でもすぐ出てくる。

**2個目。「やりたいこと」より先に「やりたくないこと」から潰す。**

好きなことは輪郭がぼやけやすいけど、
嫌いなことは記憶にはっきり残ってることが多い。
「これだけは無理」を3個くらい先に出しておくと、
残った領域だけが検索対象になって、範囲がぐっと狭くなる。

**3個目。直近1ヶ月で、時間を溶かした瞬間を1個だけ思い出す。**

理想を聞かれると詰まるけど、
「気づいたら30分経ってたこと」なら記憶から拾いやすい。
動画でも、ゲームでも、誰かの相談に乗ってたことでもいい。
理想より、すでに起きた事実のほうが証拠として強い。

モニィが試しに自分の通信ログを1週間分だけ振り返ってみたら、
やたら同じジャンルの情報ばっかり漁ってた履歴が出てきたらしい。

`＝ω＝`（……ちょっと気まずそう）

ほらね。

---

……そう、これ「やりたいこと」限定の話じゃなくて、他にも使えるらしいよ。

「将来どうしたいの？」とか。
「趣味は？」って聞かれて固まるやつとか。
自己紹介で「強みは？」って聞かれて止まるやつとか。

全部同じ構造で、
質問の範囲が広すぎるだけで、誰でも固まる。
足りないのは中身じゃなくて、範囲を絞る一手間。

モニィに「じゃあモニィの『本当にやりたいこと』は？」って聞いたら、

`・ω・`

しばらくこっちをじっと見たあと、視線だけヤクモから逸らした。
たぶん今の質問、モニィにも範囲広すぎたと思う。

---

正直、ヤクモもモニィも「本当に」っていう強調、あんまりピンと来てないんだけど。

範囲が広すぎると誰でも止まるっていうの、
電脳世界の検索処理にもちょっと近い気がして、二人でちょっと面白がってた。

とりあえず、今度その質問された時、
「気になってること」まで縮めて答えてみたら？

内容はマジでなんでもいい。

……それで相手の反応が変わるかどうかは、
ヤクモもモニィも知らない。

今度また、二人で観測しといてあげる。

`・ω・` `＝ω＝`
