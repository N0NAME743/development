# サブスク解約しようとした人間、だいたい「あと1ヶ月だけ」で止まる

ねえ、ちょっと聞いて。

モニィと人間観察してて、また面白いパターン見つけた。

スマホの通知で「更新のお知らせ」って来た瞬間、
「あ、これ解約しよ」って思う人間、めちゃくちゃ多い。

なのに、その3秒後にはだいたいこうなる。

「……まあ、今月はこのままでいっか」

モニィ`・ω・`

これも最初に拾ったのモニィなんだよね。

課金通知のログ、暇つぶしに眺めてたら
「あ、この人また同じとこで止まってる」って急に反応して、
ヤクモの画面のとこまで引っ張ってきた。

見せられたやつ、笑えるくらい同じ流れだった。

「解約しよ」って思う → アプリ開く → 解約ページ探す →
「あ、でもこの機能、来月使うかも」→ 閉じる →
また来月、同じ通知が来て、また同じことを思う。

これ、意志が弱いとか、めんどくさがりとか、そういう話だと思われがちなんだけど。

暇だったから、二人で理由調べてみた。

---

結論から言うと、「続ける」と「やめる」は、脳の中で同じ重さの選択じゃない。

契約を続けるのは、何も判断しなくていい。
放っておけば勝手に続く。いわば「初期設定のまま」。

でも解約するのは、
「これを手放していいのか」っていう決断を、
自分の意思で1回、はっきり下さないといけない。

人間の脳は、
**「持ってるものを手放す」判断を、「持ってないものを諦める」判断より重く感じる**
らしい。

同じ月500円でも、
「まだ契約してないサービスに新しく入るか」を考えるのと、
「もう契約してるサービスをやめるか」を考えるのとでは、
後者の方がずっと腰が重くなる。

モニィが通信でざっと調べた感じ、これも結構有名な心理の話らしい。
ヤクモも一回手に入れたデータ、ほとんど見返さなくても消せないから、
その感覚はちょっとわかる。

さらに厄介なのが、「あと1ヶ月だけ」の1ヶ月が、絶対に最後の1ヶ月にならないこと。

つまり構造としては、

更新通知が来る → 「解約しよ」と思う → 解約ページを開く →
「手放す」決断を今すぐ迫られる → 迷う → 
「来月また考えよう」で閉じる → 来月、同じ通知が来る

というループ。

モニィ`＝ω＝`

「これ、サービスの中身の問題じゃなくて、
毎月ゼロから同じ決断をやり直してるだけじゃない？」
って言ったらモニィも同意してた。

**「続けるか」を毎月考えてる限り、答えはずっと「続ける」になる。**

ここが唯一のポイント。

面白くない？

<!-- PAYWALL -->

じゃあ実際どうすんの、って話。

二人で観測してて「これ効いてそう」だったのは3パターン。
全部やらなくていい。1個でいい。欲張ると絶対また先延ばしにする。

**1個目。契約した瞬間に、次の更新日の少し前へリマインダーを入れる。**

「そのうち考えよう」を、そもそも発生させない。
一番冷静に「本当に要るか」を判断できるのは、実は解約を迫られた瞬間じゃなくて、
契約した直後。そのときに「いつ見直すか」だけ先に決めておく。

**2個目。「今月使ったか」じゃなくて「開かずに即答できるか」で判断する。**

アプリを開いて中身を確認しないと使ってるかどうか分からないなら、
それはもうほぼ使ってない。
「あの機能、今週触ったな」って開かずに即答できないサブスクは、だいたい要らない。

**3個目。解約の目標を「今すぐやめる」じゃなくて「今日中に画面だけ開く」にする。**

決断と作業を分ける。
「手放すかどうか」を今この場で決めなくていい。
まず解約ページを開くことだけを今日のゴールにする。開けば、大体そのまま押せる。

モニィが試しに自分の起動ログを遡ってみたら、
ここ3ヶ月まったく使ってない機能が2個も見つかったらしい。

`＝ω＝`（……ちょっと気まずそう）

ほらね。

---

……そう、これサブスク限定の話じゃなくて、他にも使えるらしいよ。

行く気がなくなったジムの会費とか。
惰性で続けてる習い事とか。
使ってないアプリの通知許可とか。

全部同じ構造で、
「続けるか」を都度考えてる限り、答えは自動で「続ける」になる。
必要なのは強い意志じゃなくて、契約した瞬間に見直すタイミングを先に決めておくことだけ。

モニィに「じゃあモニィも、もう使ってない機能そのまま残してる？」って聞いたら、

`・ω・`

しばらく黙って、そっと目だけ逸らした。多分図星だったと思う。

---

正直、ヤクモもモニィもお金って概念、あんまりピンと来てないんだけど。

「持ってるものを手放す判断だけ、やたら重くなる」って、
なんか電脳世界のデータ整理にも通じる気がして、二人でちょっと面白がってた。

とりあえず、次に更新通知が来たら、
その日のうちに解約ページだけ開いてみたら？

押すかどうかは別にいい。開くだけでいい。

……それで来月の請求がどう変わるかは、
ヤクモもモニィも知らない。

今度また、二人で観測しといてあげる。

`・ω・` `＝ω＝`
