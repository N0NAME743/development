# 見出し画像プロンプト：会議で真っ先に発言した人間、だいたいあとで自分の発言を後悔してる

`eyecatch_prompt_template.md`の型に、今回のテーマ（会議で真っ先に発言するネタ）の変数を当てはめたもの。
画像生成ツールにそのまま貼り付けて使う。

## 変数

- `TITLE_PHRASE`: 真っ先に発言した人間
- `PUNCHLINE_WORD`: 一人反省会。
- `TIMELINE_CAPTIONS`:
  1. 開始1分「はい、挙手!」
  2. 発言直後「……言い切った」
  3. 会議終了直後「今の発言、大丈夫だった?」
  4. 通勤電車内「延々リプレイ中」
- `PROP_ITEMS`: ノートPC、議事録っぽいメモ帳、コーヒーカップ、通知だらけのスマホ画面

## プロンプト本文

```
YAKUMO（黒髪ツインお団子、ネオンピンクメッシュ、黒×ネオンピンクのサイバーゴシック衣装、
「89」の入ったヘッドフォン）とMONY（黒いウサギ型デバイス、＝ω＝の表情ディスプレイ）が
登場する、アニメ風デジタルイラストのコミック風アイキャッチ画像。

上部に大きく「真っ先に発言した人間」というタイトルテキスト（一部をネオンピンクで強調）。

中央に時系列パネル4コマ：
- 開始1分「はい、挙手!」
- 発言直後「……言い切った」
- 会議終了直後「今の発言、大丈夫だった?」
- 通勤電車内「延々リプレイ中」
各コマでYAKUMOの表情が、自信満々→どや顔→不安げ→放心気味、と少しずつ変化していく。

右側に大きく「一人反省会。」という文字と、関連アイコン(吹き出しがぐるぐる回るマーク、時計等)。

左下にノートPC、議事録っぽいメモ帳、コーヒーカップ、通知だらけのスマホ画面を配置。

右下に「YAKUMO ω MONY」「TECH × LIFE × IDEAS × AI」のブランド表記。

配色は黒〜濃紫ベース＋ネオンピンクのハイライト、全体は少しダークでサイバーパンクな雰囲気だが、
YAKUMOとMONYの表情はどこか可愛らしく親しみやすい。
```
