# 見出し画像プロンプト（記事「サブスク解約しようとした人間、だいたい『あと1ヶ月だけ』で止まる」用）

`eyecatch_prompt_template.md` の型に、今回のテーマ用の変数を埋めたもの。
画像生成ツール（Codex等）にそのまま貼り付けて使う。

## 埋めた変数

- TITLE_PHRASE: 「サブスク解約しようとした人間、だいたい『あと1ヶ月だけ』で止まる」
- PUNCHLINE_WORD: 「続いてる。」
- TIMELINE_CAPTIONS:
  1. 更新通知：あ、これ解約しよ
  2. 解約ページを開く：でもこの機能、来月使うかも
  3. そっと閉じる：来月また考えよう
  4. 翌月：また同じ通知が来る
- PROP_ITEMS: スマホ（通知画面）、クレジットカード、解約ボタンのアイコン、カレンダー

## プロンプト本文

```
YAKUMO（黒髪ツインお団子、ネオンピンクメッシュ、黒×ネオンピンクのサイバーゴシック衣装、
「89」の入ったヘッドフォン）とMONY（黒いウサギ型デバイス、＝ω＝の表情ディスプレイ）が
登場する、アニメ風デジタルイラストのコミック風アイキャッチ画像。

上部に大きく「サブスク解約しようとした人間、だいたい『あと1ヶ月だけ』で止まる」という
タイトルテキスト（「あと1ヶ月だけ」の部分をネオンピンクで強調）。

中央に時系列パネル4コマ：
- 更新通知：あ、これ解約しよ
- 解約ページを開く：でもこの機能、来月使うかも
- そっと閉じる：来月また考えよう
- 翌月：また同じ通知が来る
各コマでYAKUMOの表情・状況が少しずつ変化していく（最初はやる気、最後は諦め顔）。

右側に大きく「続いてる。」という文字と、ぐるぐる回る更新アイコンのような関連アイコン。

左下にスマホ（通知画面）・クレジットカード・解約ボタンのアイコン・カレンダーを配置。

右下に「YAKUMO ω MONY」「TECH × LIFE × IDEAS × AI」のブランド表記。

配色は黒〜濃紫ベース＋ネオンピンクのハイライト、全体は少しダークで
サイバーパンクな雰囲気だが、YAKUMOとMONYの表情はどこか可愛らしく親しみやすい。
```
