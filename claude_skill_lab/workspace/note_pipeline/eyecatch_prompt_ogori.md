# 見出し画像プロンプト（記事#8「誰かに奢った人間、だいたい奢られた本人よりよく覚えてる」用）

`eyecatch_prompt_template.md`の型に、今回のテーマ（奢った側だけが記憶に残る非対称性）を当てはめたもの。
このテキストをそのまま画像生成ツールへ貼り付けて使う。

## 変数の割り当て

- `TITLE_PHRASE`: 「奢った側だけ、覚えてる。」
- `PUNCHLINE_WORD`: 「覚えてない。」
- `TIMELINE_CAPTIONS`:
  1. 「奢った日：上機嫌で会計を済ませるYAKUMO」
  2. 「1ヶ月後：『あの時さ』と話しかけるYAKUMO、キョトンとする相手」
  3. 「3ヶ月後：金額まで正確に覚えてるYAKUMO」
  4. 「相手：『そんなことありました…？』」
- `PROP_ITEMS`: 丸まったレシート、割り勘アプリの画面、空になったコーヒーカップ

## プロンプト本文（コピペ用）

```
YAKUMO（黒髪ツインお団子、ネオンピンクメッシュ、黒×ネオンピンクのサイバーゴシック衣装、
「89」の入ったヘッドフォン）とMONY（黒いウサギ型デバイス、＝ω＝の表情ディスプレイ）が
登場する、アニメ風デジタルイラストのコミック風アイキャッチ画像。

上部に大きく「奢った側だけ、覚えてる。」というタイトルテキスト（一部をネオンピンクで強調）。

中央に時系列パネル4コマ：
- 奢った日：上機嫌で会計を済ませるYAKUMO
- 1ヶ月後：「あの時さ」と話しかけるYAKUMO、キョトンとする相手
- 3ヶ月後：金額まで正確に覚えてるYAKUMO
- 相手：「そんなことありました…？」
各コマでYAKUMOの表情・テンションが少しずつ盛り下がっていく。

右側に大きく「覚えてない。」という文字と、記憶が薄れていくようなアイコン（吹き出しが消えかけている、頭の中に？マーク）。

左下に丸まったレシート、割り勘アプリの画面、空になったコーヒーカップを配置。

右下に「YAKUMO ω MONY」「TECH × LIFE × IDEAS × AI」のブランド表記。

配色は黒〜濃紫ベース＋ネオンピンクのハイライト、全体は少しダークで
サイバーパンクな雰囲気だが、YAKUMOとMONYの表情はどこか可愛らしく親しみやすい。
```
