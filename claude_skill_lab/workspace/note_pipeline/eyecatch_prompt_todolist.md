# 見出し画像プロンプト：「タスクリストに書いた人間、だいたい書いた時点で終わった気になってる」

`eyecatch_prompt_template.md`の型に、今回のテーマ（#14 タスクリスト）の変数を埋めたもの。
以下のプロンプト本文をそのままCodex等の画像生成ツールに貼り付ける。

## 埋めた変数

- `TITLE_PHRASE`: 「書いた瞬間、終わった気になる」
- `PUNCHLINE_WORD`: 「書いただけ。」
- `TIMELINE_CAPTIONS`:
  1. AM9:00「リストに5個書き出す、謎の達成感MAX」
  2. PM12:00「1個も手つけてないのに謎の余裕」
  3. PM6:00「リストの存在、もう忘れてる」
  4. 翌朝「同じタスク、また書いてる」
- `PROP_ITEMS`: 付箋、ボールペン、タスクリストのメモ帳、コーヒーカップ

## プロンプト本文

```
YAKUMO（黒髪ツインお団子、ネオンピンクメッシュ、黒×ネオンピンクのサイバーゴシック衣装、
「89」の入ったヘッドフォン）とMONY（黒いウサギ型デバイス、＝ω＝の表情ディスプレイ）が
登場する、アニメ風デジタルイラストのコミック風アイキャッチ画像。

上部に大きく「書いた瞬間、終わった気になる」というタイトルテキスト（一部をネオンピンクで強調）。

中央に時系列パネル4コマ：
- AM9:00「リストに5個書き出す、謎の達成感MAX」
- PM12:00「1個も手つけてないのに謎の余裕」
- PM6:00「リストの存在、もう忘れてる」
- 翌朝「同じタスク、また書いてる」
各コマでYAKUMOの表情・状況が少しずつ変化していく。

右側に大きく「書いただけ。」という文字と、関連アイコン（チェックの付いていないToDoリスト、時計）。

左下に付箋、ボールペン、タスクリストのメモ帳、コーヒーカップを配置。

右下に「YAKUMO ω MONY」「TECH × LIFE × IDEAS × AI」のブランド表記。

配色は黒〜濃紫ベース＋ネオンピンクのハイライト、全体は少しダークで
サイバーパンクな雰囲気だが、YAKUMOとMONYの表情はどこか可愛らしく親しみやすい。
```
