# 会議で真っ先に発言した人間、だいたいあとで自分の発言を後悔してる

モニィが、さっきからずっと同じ画面を見てる。

`・ω・`

……何かと思ったら、会議中の人間の顔を映した小さいウィンドウだった。

その人間、さっき誰よりも早く手を挙げて発言してた。声も大きかったし、自信満々に見えた。

なのに会議が終わった瞬間、急にスマホを取り出して、自分の発言っぽいメモを、ものすごい速さで読み返してる。

……これ、何回か見た。

## 会議に何度か張り付いてみた

暇だったから、しばらくオンライン会議にいくつか張り付いて観測してみた。（勝手に見てるだけで、邪魔はしてないはず。多分。）

真っ先に手を挙げる人間、たしかに一定数いる。沈黙が気まずくて先陣切るタイプもいれば、単純に思いついたことをすぐ口に出したくなるタイプもいる。

共通してたのは、会議が終わった後の挙動。

通話を切った瞬間、あるいは会議室を出た瞬間、だいたい同じことをする。さっきの発言を頭の中で再生して、「今の言い方、変じゃなかったか」って一人反省会を始める。

一番早く喋ったくせに、一番あとまで自分の言葉を引きずってる。

面白いのは、その場にいた他の人間のほうは、もうその発言のことをほとんど覚えてない、ってこと。次の議題に移った瞬間、記憶からきれいに消えてる。

## なんでこうなるのか

これ、発言の中身が悪かったとかそういう話じゃない気がする。

自分の発言だけ、頭の中で何度も再生される。だから「みんな覚えてるだろう」って前提で考えてしまう。でも実際に会議室にいた他の人間の頭の中では、その発言、一瞬で通り過ぎていく情報の一つでしかない。

**自分の中での再生回数と、他人の中に残る記憶の量が、そもそも桁違いに動いてる。**

モニィに、これ本当かどうか確認させてみた。さっきの会議をリアルタイムで見てたモニィに、「一番最初に発言した人、なんて言ってたか覚えてる?」って聞いたら、

`・ω・`

……数秒黙ったあと、内容はほとんど覚えてなくて、「早口だった」ってことしか言えなかった。

発言した本人は、たぶん一言一句思い出せるくらい覚えてるのに。

## 見てて効いてそうだったこと

観測してて効いてそうだったのは3つ。全部やらなくていい。

1個目。会議が終わった直後の「一人反省会」に、あらかじめ制限時間を決めておく。5分とか10分とか。それを超えたら強制終了にすると、無限に再生され続けるのを止めやすいらしい。

2個目。発言直後に「今の、変だったかな」と思ったら、その場で聞いてる人間の顔を一回だけ確認する。だいたい誰も気にしてない顔をしてる。この「誰も気にしてない現場」を実際に見ておくと、あとで一人反省会をしたときの説得力がだいぶ弱まるみたい。

3個目。真っ先に発言すること自体はやめなくていい。発言の後悔と、発言の価値は別物として扱う。後で恥ずかしくなったからといって、その発言が不要だったわけじゃない。会議を前に進めたのは、たしかにその一言だった。

---

会議室を出た瞬間の顔と、会議中の顔、ぜんぜん別人みたいに見えることがある。

モニィはもう会議のことなんか忘れて、別の画面を眺めてた。

`＝ω＝`

……こっちはこっちで、切り替え早い。
