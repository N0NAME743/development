# 見出し画像プロンプト：「そろそろ帰ろうか」って言い出す人間、だいたい一番名残惜しがってる

`eyecatch_prompt_template.md`の型に、今回のテーマ（解散を言い出す人ほど名残惜しいネタ）の変数を当てはめたもの。
画像生成ツールにそのまま貼り付けて使う。

## 変数

- `TITLE_PHRASE`: 「そろそろ」って言い出す人間
- `PUNCHLINE_WORD`: 一番、名残惜しい。
- `TIMELINE_CAPTIONS`:
  1. 会計後「そろそろ……帰ろっか」
  2. 玄関先「じゃあ、また今度」
  3. 帰り道「……もうちょい話したかったな」
  4. 電車内「一人反省会、開催中」
- `PROP_ITEMS`: 会計伝票、居酒屋のジョッキ、コート、スマホ（時計表示）

## プロンプト本文

```
YAKUMO（黒髪ツインお団子、ネオンピンクメッシュ、黒×ネオンピンクのサイバーゴシック衣装、
「89」の入ったヘッドフォン）とMONY（黒いウサギ型デバイス、＝ω＝の表情ディスプレイ）が
登場する、アニメ風デジタルイラストのコミック風アイキャッチ画像。

上部に大きく「「そろそろ」って言い出す人間」というタイトルテキスト（一部をネオンピンクで強調）。

中央に時系列パネル4コマ：
- 会計後「そろそろ……帰ろっか」
- 玄関先「じゃあ、また今度」
- 帰り道「……もうちょい話したかったな」
- 電車内「一人反省会、開催中」
各コマでYAKUMOの表情が、笑顔→名残惜しそうな半笑い→ちょっと切なげ→放心気味、と少しずつ変化していく。

右側に大きく「一番、名残惜しい。」という文字と、関連アイコン(時計、吹き出し、涙ぐむ絵文字風マーク等)。

左下に会計伝票、居酒屋のジョッキ、コート、スマホ（時計表示）を配置。

右下に「YAKUMO ω MONY」「TECH × LIFE × IDEAS × AI」のブランド表記。

配色は黒〜濃紫ベース＋ネオンピンクのハイライト、全体は少しダークでサイバーパンクな雰囲気だが、
YAKUMOとMONYの表情はどこか可愛らしく親しみやすい。
```
