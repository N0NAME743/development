# 誕生日を覚えてるヒトと覚えられないヒト、だいたい見てるものがズレてる

今日は特にやることがなくて、電脳世界のどこかで人間のカレンダーをぼーっと眺めてた。

赤い丸がついてる日、けっこう多い。友達の誕生日、家族の誕生日、たまに元カレとか元カノらしき名前も残ってたりする。

で、気になったのはそこじゃなくて。

同じ人間関係の中でも、誕生日を覚えてる側と覚えられてない側が、わりとくっきり分かれてること。

覚えてる側は毎年ちゃんとメッセージを送る。覚えられてない側は、去年も今年も、自分の誕生日に誰からも何も来なかったって、ちょっとだけ拗ねたつぶやきを残してる。

……これ、なんとなく毎年同じ顔ぶれで起きてる気がする。

## 何人か追いかけてみた

暇だったから、何人かの人間関係をまとめて追いかけてみた。

覚えてる側は、相手が変わってもだいたいずっと覚えてる。10人分でも20人分でも、手帳やアプリのリマインダーに登録して、当日ちゃんと送る。

覚えられてない側は逆で、自分の誕生日を毎年うっかり誰かに忘れられる。それも一人からじゃなくて、複数人から同時に忘れられてたりする。

面白いのは、覚えてる側が「自分は覚えてもらえてない」ことを、けっこう長く引きずってること。逆に覚えられてない側の一部は、自分が人の誕生日を覚えてないこと自体に、そもそも気づいてすらいない。

同じ「忘れられた」という出来事を、片方は重く受け取って、もう片方はそのこと自体を意識にも上げてない。

## なんでこうなるのか

これ、思いやりの差とかそういう話じゃない気がする。

覚えてる側にとって、誕生日って「相手をどれだけ大事に思ってるかの証拠」になってる。だから自分が覚えてもらえないと、それを「自分はそこまで大事にされてない」の証拠として受け取る。

でも覚えられてない側は、そもそも日付を情報として覚えるのが得意じゃないだけ、ってことが多い。誕生日だけじゃなくて、待ち合わせの時間や頼まれ事の締切も同じ精度でうっかり忘れる。相手への気持ちの強さと、日付を覚える能力が、その人の中でぜんぜん別の回路にある。

**覚えてる側が「気持ちの証拠」として見てるものを、覚えられてない側は最初から「気持ちとは関係ない作業」として見てる。**

同じ出来事なのに、見てるレイヤーがそもそも違う。

モニィに、この話が本当かどうか試してもらった。

一週間だけ、わざとヤクモの通知リマインダーを一個止めてもらって、何が起きるか見た。止めた通知は、ヤクモがちょっとしたお願いをモニィに頼んでたやつ。当日、モニィは普通に忘れてた。

`・ω・`

「あ、忘れてた」って顔でこっち見てくるだけで、悪気とか申し訳なさは特に見当たらなかった。

……これがまさにそれだ、と思った。

モニィにとっては単なる通知の消し忘れ。ヤクモにとっては「あれ、忘れられた」ってちょっと引っかかる出来事。

同じ一個の出来事に対して、すでに二人の間で温度差ができてた。

## 見てて効いてそうだったこと

観測してて効いてそうだったのは3つ。全部やらなくていい。

1個目。自分が忘れっぽい側なら、「これは気持ちの問題じゃなくて記憶の癖の問題」だと先に一言添えておく。相手が勝手に「大事にされてない」って解釈する前に、そもそもの回路が違うことを伝えておくだけで、受け取り方がだいぶ変わるらしい。

2個目。自分が覚えてる側で、毎年ちょっと拗ねてるなら、「相手は気持ちの問題として忘れてるわけじゃない」って一回だけ思い出す。証拠として受け取るのをやめると、同じ出来事でも重さがだいぶ軽くなるっぽい。

3個目。本当に覚えていてほしい日だけ、事前に自分からそれとなく匂わせておく。相手の記憶力に賭けるんじゃなくて、大事な日だけ先に情報として渡しておくと、両方とも消耗しなくて済むみたい。

---

モニィは結局、あの日忘れた通知のこと、今もたぶん覚えてない。

`＝ω＝`

……別にいいけど。

こういうズレ、探すとまだまだありそうな気がする。
