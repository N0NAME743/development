# 見出し画像プロンプト：「今ちょっといいですか」で呼ばれた人間、だいたいその後30分は使い物にならない

`eyecatch_prompt_template.md` の型に、今回のテーマ（仕事編／中断と集中力）の変数を当てはめたもの。
画像生成ツールにそのまま貼り付けて使う想定。

## 変数の当てはめ

- `TITLE_PHRASE`: 今ちょっといいですか
- `PUNCHLINE_WORD`: −30分。
- `TIMELINE_CAPTIONS`:
  1. 集中して作業中（指の動きが速い、画面にコードや文章がびっしり）
  2. 後ろから肩を叩かれ「今ちょっといいですか」と話しかけられる瞬間
  3. 会話が終わり画面に向き直るが、カーソルだけが点滅して指が止まっている
  4. 時計が30分進んでいるのに、画面の作業はほぼ変化していない
- `PROP_ITEMS`: 付箋（「どこまでやったか」のメモ）、コーヒーカップ、通知アイコン、ヘッドフォン

## プロンプト本文（そのままコピペ用）

```
YAKUMO（黒髪ツインお団子、ネオンピンクメッシュ、黒×ネオンピンクのサイバーゴシック衣装、
「89」の入ったヘッドフォン）とMONY（黒いウサギ型デバイス、＝ω＝の表情ディスプレイ）が
登場する、アニメ風デジタルイラストのコミック風アイキャッチ画像。

上部に大きく「今ちょっといいですか」というタイトルテキスト（一部をネオンピンクで強調）。

中央に時系列パネル4コマ：
- 集中して作業中（指の動きが速い、画面にコードや文章がびっしり）
- 後ろから肩を叩かれ「今ちょっといいですか」と話しかけられる瞬間
- 会話が終わり画面に向き直るが、カーソルだけが点滅して指が止まっている
- 時計が30分進んでいるのに、画面の作業はほぼ変化していない
各コマでYAKUMOの表情・状況が少しずつ変化していく（集中顔→振り向く驚き顔→呆然とした顔→気まずい苦笑い）。

右側に大きく「−30分。」という文字と、時計やカーソル点滅を思わせるアイコン。

左下に付箋（「どこまでやったか」のメモ）、コーヒーカップ、通知アイコン、ヘッドフォンを配置。

右下に「YAKUMO ω MONY」「TECH × LIFE × IDEAS × AI」のブランド表記。

配色は黒〜濃紫ベース＋ネオンピンクのハイライト、全体は少しダークでサイバーパンクな雰囲気だが、
YAKUMOとMONYの表情はどこか可愛らしく親しみやすい。
```
