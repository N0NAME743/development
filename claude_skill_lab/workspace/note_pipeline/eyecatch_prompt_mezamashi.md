# 見出し画像プロンプト：目覚まし何個もセットする人間、だいたい最初の1個で終わってる

`eyecatch_prompt_template.md`の型に、今回のテーマ（目覚まし複数セット）を当てはめたもの。
以下のプロンプト本文をそのままCodex等の画像生成ツールに貼り付ける。

## 変数の中身

- `{TITLE_PHRASE}`: 「目覚まし何個もセットする人間」
- `{PUNCHLINE_WORD}`: 「1個目で終了。」
- `{TIMELINE_CAPTIONS}`:
  1. 5:50「起きる」
  2. 6:00「本当に起きる」
  3. 6:10〜6:30「（鳴った形跡なし）」
  4. 起床後「……あれ、意味あった?」
- `{PROP_ITEMS}`: スマホ（アラーム一覧画面）、布団、目覚まし時計のアイコン、Zzzマーク

## プロンプト本文

```
YAKUMO（黒髪ツインお団子、ネオンピンクメッシュ、黒×ネオンピンクのサイバーゴシック衣装、
「89」の入ったヘッドフォン）とMONY（黒いウサギ型デバイス、＝ω＝の表情ディスプレイ）が
登場する、アニメ風デジタルイラストのコミック風アイキャッチ画像。

上部に大きく「目覚まし何個もセットする人間」というタイトルテキスト（一部をネオンピンクで強調）。

中央に時系列パネル4コマ：
- 5:50「起きる」
- 6:00「本当に起きる」
- 6:10〜6:30「（鳴った形跡なし）」
- 起床後「……あれ、意味あった?」
各コマでYAKUMOの表情・状況が少しずつ変化していく（最初は真剣、最後は寝坊して焦っている）。

右側に大きく「1個目で終了。」という文字と、目覚まし時計・Zzzマークのアイコン。

左下にスマホのアラーム一覧画面（5:50/6:00/6:10/6:20/6:30と並んだリスト）、
布団、目覚まし時計のアイコンを配置。

右下に「YAKUMO ω MONY」「TECH × LIFE × IDEAS × AI」のブランド表記。

配色は黒〜濃紫ベース＋ネオンピンクのハイライト、全体は少しダークで
サイバーパンクな雰囲気だが、YAKUMOとMONYの表情はどこか可愛らしく親しみやすい。
```
