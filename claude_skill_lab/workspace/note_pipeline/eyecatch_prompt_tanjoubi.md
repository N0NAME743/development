# 見出し画像プロンプト：誕生日を覚えてるヒトと覚えられないヒト、だいたい見てるものがズレてる

`eyecatch_prompt_template.md`の型に、今回のテーマ（誕生日を覚えてる側／覚えられない側の温度差）を当てはめたもの。
以下のプロンプト本文をそのままCodex等の画像生成ツールに貼り付ける。

## 変数の中身

- `{TITLE_PHRASE}`: 「誕生日を覚えてるヒトと覚えられないヒト」
- `{PUNCHLINE_WORD}`: 「温度差。」
- `{TIMELINE_CAPTIONS}`:
  1. 「送る側」スマホのリマインダー通知一覧（何人分も登録されている）
  2. 「送られない側」誰からもメッセージが来ない誕生日当日の画面
  3. 送る側が「今年も誰も気づいてない」とちょっと拗ねる表情
  4. 送られない側は他人の誕生日をそもそも忘れていて無自覚な表情
- `{PROP_ITEMS}`: カレンダー（赤丸がついた日付）、スマホのリマインダー通知画面、ケーキの絵文字

## プロンプト本文

```
YAKUMO（黒髪ツインお団子、ネオンピンクメッシュ、黒×ネオンピンクのサイバーゴシック衣装、
「89」の入ったヘッドフォン）とMONY（黒いウサギ型デバイス、＝ω＝の表情ディスプレイ）が
登場する、アニメ風デジタルイラストのコミック風アイキャッチ画像。

上部に大きく「誕生日を覚えてるヒトと覚えられないヒト」というタイトルテキスト（一部をネオンピンクで強調）。

中央に時系列パネル4コマ：
- 送る側のスマホ：何人分もの誕生日リマインダー通知が並んでいる画面
- 送られない側のスマホ：誕生日当日なのに誰からもメッセージが来ていない画面
- 送る側が「今年も誰も気づいてない」とちょっと拗ねた表情でスマホを見ている
- 送られない側は他人の誕生日をそもそも忘れていて、きょとんとした無自覚な表情
各コマでYAKUMOの表情・状況が少しずつ変化していく。

右側に大きく「温度差。」という文字と、ケーキの絵文字・通知アイコン。

左下にカレンダー（赤丸のついた日付）とスマホのリマインダー通知画面を配置。

右下に「YAKUMO ω MONY」「TECH × LIFE × IDEAS × AI」のブランド表記。

配色は黒〜濃紫ベース＋ネオンピンクのハイライト、全体は少しダークで
サイバーパンクな雰囲気だが、YAKUMOとMONYの表情はどこか可愛らしく親しみやすい。
```
