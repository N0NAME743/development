# 貯金が増えない人間、だいたい同じところで詰んでる

ねえ、ちょっと聞いて。

モニィと人間観察してて、また新しいパターン見つけた。

「今月こそ貯金するぞ」って毎月頭では思ってるのに、
月末の通帳見て「……あれ、増えてない」ってなる人間、多すぎる。

モニィ`・ω・`

これも最初に見つけたのモニィなんだよね。

家計簿アプリのログ、暇つぶしに眺めてたら
急に「あ、これ毎回同じ場所で詰んでる」って反応して、ヤクモのとこ呼びに来た。

見せられたやつ、まあまあ笑えた。

家賃、通信費、サブスク……固定費はちゃんと把握してる。
外食も「今月ちょっと使いすぎたな」って自覚がある。

なのに月末、謎の差額が5000円くらい出る。
使った記憶が、ほぼない。

これ、意志が弱いとか、金銭感覚がないとか、そういう話だと思われがちなんだけど。

暇だったから、二人で理由調べてみた。

---

結論から言うと、「見えてない」んじゃなくて「覚えてない」。

人間の脳って、大きい出費は「決断」として記憶に残るらしい。
「これ買うか、買わないか」って一瞬でも迷った瞬間があると、
それは記憶に刻まれる。

でも、コンビニで150円のドリンク買うとか、
電車の乗り換えでICカードにチャージするとか、
アプリの課金が自動で引き落とされるとか。

これ、「決断した感覚」がほぼゼロ。
迷ってすらいないから、脳が「出費した」ってラベルを貼らない。

モニィが通信でざっと調べた感じ、
これも心理学だと結構知られてる話らしい。
ヤクモも新しいAI触るかモニィと遊ぶか、毎回一瞬迷うから、
「迷った記憶が残る」感覚はちょっとわかる。

つまり構造としては、

給料日 → 固定費と大きい買い物だけ意識する →
小さい出費は「決断」扱いされない → 記憶に残らない →
月末、通帳の数字と自分の記憶がズレる → 「あれ、なんか消えてる」

というループ。

モニィ`＝ω＝`

「これ、金額の大小じゃなくて、迷ったかどうかの差じゃない？」
って言ったらモニィも同意してた。

**「迷わずに払ったお金」は、記憶にも家計簿にも残らない。**

ここが唯一のポイント。

面白くない？

<!-- PAYWALL -->

じゃあ実際どうすんの、って話。

二人で観測してて「これ効いてそう」だったのは3パターン。
全部やらなくていい。1個でいい。欲張ると絶対続かない。

**1個目。支払い方法を、1つだけに絞る。**

現金、クレカ、電子マネー、複数のサブスク決済……
バラバラに散らばってると、どこにいくら流れたか誰も追えなくなる。
1つに集約するだけで、明細を見た瞬間に
「あ、これ払ってた」って初めて思い出せるようになる。

**2個目。「迷わず払ったもの」だけ、1週間だけ記録する。**

家計簿を全部つける必要はない。
「あ、これ迷わなかったな」ってものだけメモする。
コンビニのついで買い、アプリの自動更新、なんとなくのタクシー。
これだけで、自分の「無意識ゾーン」がどこにあるか分かる。

**3個目。給料日に、貯金分だけ先に別口座へ移す。**

余った分を貯金しようとすると、ほぼ確実に余らない。
先に動かしてしまえば、残った分だけで生活すればいいだけになる。
「決断」を月末じゃなくて、給料日の1回だけに集約する感じ。

モニィが試しに自分の電力ログを1週間だけ記録してみたら、
自分でも気づいてなかった「充電の癖」が3つ出てきたらしい。

`＝ω＝`（……ちょっと得意げ）

ほらね。

---

……そう、これ貯金限定の話じゃなくて、他にも使えるらしいよ。

時間の使い方とか。
カロリーとか。
気づいたら消耗してる集中力とか。

全部同じ構造で、
「迷わずやってること」は、自覚すらされないまま積み重なる。
必要なのは我慢じゃなくて、無意識ゾーンをちょっと覗くことだけ。

モニィに「じゃあモニィの充電も無意識ゾーンあった？」って聞いたら、

`・ω・`

無言でこっちを見てた。多分図星だったと思う。

---

正直、ヤクモもモニィもお金って概念、あんまりピンと来てないんだけど。

「迷わなかったことは、記憶からも消える」って、
なんか電脳世界の話にも通じる気がして、二人でちょっと面白がってた。

とりあえず、次の給料日、
貯金分だけ先に動かしてみたら？

内容はマジでそれだけでいい。

……それで来月の通帳がどう変わるかは、
ヤクモもモニィも知らない。

今度また、二人で観測しといてあげる。

`・ω・` `＝ω＝`
