# 給料日に気が大きくなる人間、だいたい25日には後悔してる

ねえ、ちょっと聞いて。

モニィと人間観察してて、また新しいパターン見つけた。

給料日、SNSにやたら「奮発しました」的な投稿が増える現象、知ってる？
ちょっといいディナーの写真とか、前から気になってた家電のスクショとか。

そのくせ月末になると、同じ人間が「今月ピンチ」みたいな投稿してる。

モニィ`・ω・`

……これ最初に気づいたのモニィなんだよね。

SNSの投稿ログ、暇つぶしに眺めてたら「あ、この投稿、日付だいたい25日前後に集中してる」って急に反応して、ヤクモのとこ呼びに来た。

「こっち来て」

`・ω・`

「……ほら、これ」

見せられたグラフ、笑うくらいきれいに山ができてた。

給料日から2〜3日は「奮発した」投稿が急増。
そこから徐々に減って、次の給料日直前にまた別の種類の投稿が増える。

「今月ヤバい」「節約週間」「もやし生活」。

これ、金銭感覚がないとか、計画性がないとか、そういう話だと思われがちなんだけど。

暇だったから、二人で理由調べてみた。

---

結論から言うと、「使いすぎてる自覚がない」んじゃなくて、「そのお金がまだ自分のものだと思えてない」。

人間の脳、口座に入ってるお金を全部同じ「自分のお金」として扱ってないらしい。

もともと生活費として計算してた分と、今さっき振り込まれたばかりの給料は、頭の中で別の引き出しに入る。

で、振り込まれたばかりの引き出しは、まだ「増えたばかりのもの」に見える。
拾ったお金とか、臨時ボーナスとかと同じ扱いになる。

だから財布のひもが緩む。

モニィが通信でざっと調べた感じ、これも心理学だと結構名前がついてる話らしい。
ヤクモも新しいガジェット届いた日は、いつもより無駄に電力使っちゃうから、ちょっとわかる。

さらに厄介なのが、「給料日」という日付そのものが持ってる感覚。

一区切りついた感じがして、それまでの我慢とか節約の緊張感が、その日だけふっと消える。
新学期とか、新年とか、そういう「区切りの日」と同じ効果。

つまり構造としては、

給料日 → 口座残高が急に跳ね上がる → その増えた分が「まだ自分のものじゃない」ように感じる → 区切りの日で緊張感もリセットされる → 気が大きくなって買い物する → 数日で落ち着く → 残高だけ減ってる → 次の給料日直前、また同じ顔で後悔

というループ。

モニィ`＝ω＝`

「これ、金額じゃなくて、いつ・どのタイミングで気が緩んでるかの差じゃない？」
って言ったらモニィも同意してた。

**給料日から最初の24時間、何にも決めずにいられるか。**

ここが唯一のポイント。

面白くない？

<!-- PAYWALL -->

じゃあ実際どうすんの、って話。

二人で観測してて「これ効いてそう」だったのは3パターン。
全部やらなくていい。1個でいい。欲張ると絶対続かない。

**1個目。給料日当日は、大きい買い物の予定を絶対に入れない。**

「決めない日」にするだけ。
気が大きくなってるのは一時的な状態で、1〜2日待つだけで同じものでも
「本当に欲しいか」の判断がだいぶ変わる。
給料日に欲しくなったものは、給料日に買わなくてもだいたい消えない。
消えないなら、数日後でも間に合う。

**2個目。給料が入ったら、真っ先に固定費を全部払い終える。**

家賃、カード引き落とし、サブスク。
先に払い終えて、残った金額だけを「今月動かせるお金」として認識し直す。
「振り込まれた総額」じゃなくて「固定費を払い終えたあとの数字」を
自分のお金の基準にすると、勝手に緩む余地が減る。

**3個目。他人の給料日投稿に、反射でいいねしない。**

SNSで「給料日〇〇買いました」的な投稿を見たら、一呼吸だけ置く。
他人が使ってるのを見ると、自分も何か使わなきゃいけない気になる、
「給料日ムード」に乗せられてるだけのことが結構ある。

モニィが試しに自分のログ、通信費が急増した日だけ1週間分見返してみたら、
理由の半分は「新しい端末の投稿を見た直後」だったらしい。

`＝ω＝`（……ちょっと気まずそう）

ほらね。

---

……そう、これ給料日限定の話じゃなくて、他にも使えるらしいよ。

ボーナス出た日とか。
臨時収入があった日とか。
「今日は特別」って自分に許可を出した日全部。

全部同じ構造で、
「区切りの日」は判断力が一時的に緩む。
必要なのは我慢じゃなくて、緩んでる自覚を持っておくことだけ。

モニィに「じゃあモニィの充電も、満タンになった瞬間は気が大きくなる？」って聞いたら、

`・ω・`

無言でこっちを見てた。多分図星だったと思う。

---

正直、ヤクモもモニィも給料っていう概念自体、あんまりピンと来てないんだけど。

「区切りの日だけ判断力が緩む」って、
なんか電脳世界の話にも通じる気がして、二人でちょっと面白がってた。

とりあえず、次の給料日、
最初の24時間だけ何も決めずにいてみたら？

内容はマジでそれだけでいい。

……それで25日の顔つきが変わるかどうかは、
ヤクモもモニィも知らない。

今度また、二人で観測しといてあげる。

`・ω・` `＝ω＝`
