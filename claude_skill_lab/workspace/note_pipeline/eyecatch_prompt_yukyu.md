# 見出し画像プロンプト:「有給取った人間、だいたい休んでる最中も仕事のこと考えてる」

`eyecatch_prompt_template.md`の変数を今回のテーマ用に埋めたもの。
そのまま画像生成ツールに貼り付けて使う。

## 変数の中身

- `{TITLE_PHRASE}`: 有給取った人間、だいたい休んでる最中も仕事のこと考えてる
- `{PUNCHLINE_WORD}`: 休めてない。
- `{TIMELINE_CAPTIONS}`:
  1. AM9:00「今日は完全オフ」宣言
  2. AM11:00 気づけばチャットアプリを開いてる
  3. PM1:00 時計を見て「今頃会議中か」
  4. PM6:00 結局チェックして一安心
- `{PROP_ITEMS}`: 「有給」に丸をつけたカレンダー、通知バッジが増えたスマホ、飲みかけのコーヒーカップ、閉じてるのにうっすら光ってるノートPC

## プロンプト本文（このままコピペして使う）

```
YAKUMO（黒髪ツインお団子、ネオンピンクメッシュ、黒×ネオンピンクのサイバーゴシック衣装、
「89」の入ったヘッドフォン）とMONY（黒いウサギ型デバイス、＝ω＝の表情ディスプレイ）が
登場する、アニメ風デジタルイラストのコミック風アイキャッチ画像。

上部に大きく「有給取った人間、だいたい休んでる最中も仕事のこと考えてる」というタイトル
テキスト（「休んでる最中も」の部分をネオンピンクで強調）。

中央に時系列パネル4コマ：
- AM9:00「今日は完全オフ」宣言
- AM11:00 気づけばチャットアプリを開いてる
- PM1:00 時計を見て「今頃会議中か」
- PM6:00 結局チェックして一安心
各コマでYAKUMOの表情・状況が少しずつ変化していく(最初は余裕、だんだんそわそわ、最後は
バツが悪そうな笑顔)。

右側に大きく「休めてない。」という文字と、時計のアイコン。

左下に「有給」に丸をつけたカレンダー、通知バッジが増えたスマホ、飲みかけのコーヒーカップ、
閉じてるのにうっすら光ってるノートPCを配置。

右下に「YAKUMO ω MONY」「TECH × LIFE × IDEAS × AI」のブランド表記。

配色は黒〜濃紫ベース＋ネオンピンクのハイライト、全体は少しダークでサイバーパンクな雰囲気
だが、YAKUMOとMONYの表情はどこか可愛らしく親しみやすい。
```
