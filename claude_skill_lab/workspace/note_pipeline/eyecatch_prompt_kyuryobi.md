# 見出し画像プロンプト（記事「給料日に気が大きくなる人間、だいたい25日には後悔してる」用）

`eyecatch_prompt_template.md` の型に、今回のテーマ用の変数を埋めたもの。
画像生成ツール（Codex等）にそのまま貼り付けて使う。

## 埋めた変数

- TITLE_PHRASE: 「給料日に気が大きくなる人間、だいたい25日には後悔してる」
- PUNCHLINE_WORD: 「空っぽ。」
- TIMELINE_CAPTIONS:
  1. 給料日：奮発してディナー
  2. 給料日+3日：気になってた家電、ポチる
  3. 第2週：残高、ちょっと不安
  4. 25日：通帳見て真顔
- PROP_ITEMS: レシート、財布、スマホ（SNS投稿画面）、通帳

## プロンプト本文

```
YAKUMO（黒髪ツインお団子、ネオンピンクメッシュ、黒×ネオンピンクのサイバーゴシック衣装、
「89」の入ったヘッドフォン）とMONY（黒いウサギ型デバイス、＝ω＝の表情ディスプレイ）が
登場する、アニメ風デジタルイラストのコミック風アイキャッチ画像。

上部に大きく「給料日に気が大きくなる人間、だいたい25日には後悔してる」というタイトルテキスト
（「気が大きくなる」の部分をネオンピンクで強調）。

中央に時系列パネル4コマ：
- 給料日：奮発してディナー
- 給料日+3日：気になってた家電、ポチる
- 第2週：残高、ちょっと不安
- 25日：通帳見て真顔
各コマでYAKUMOの表情・状況が少しずつ変化していく（最初は上機嫌、最後は放心気味）。

右側に大きく「空っぽ。」という文字と、財布や通帳が軽くしぼんだような関連アイコン。

左下にレシート・財布・スマホ（SNS投稿画面）・通帳を配置。

右下に「YAKUMO ω MONY」「TECH × LIFE × IDEAS × AI」のブランド表記。

配色は黒〜濃紫ベース＋ネオンピンクのハイライト、全体は少しダークで
サイバーパンクな雰囲気だが、YAKUMOとMONYの表情はどこか可愛らしく親しみやすい。
```
