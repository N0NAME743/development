# 見出し画像プロンプト：しんどい日ほどSNSで元気アピールしてる人間、だいたい後から自分の投稿に一番傷ついてる

`eyecatch_prompt_template.md`の型に、今回のテーマ（しんどい日ほど元気アピール投稿）を当てはめたもの。
以下のプロンプト本文をそのままCodex等の画像生成ツールに貼り付ける。

## 変数の中身

- `{TITLE_PHRASE}`: 「しんどい日ほど元気アピールしてる人間」
- `{PUNCHLINE_WORD}`: 「ブーメラン。」
- `{TIMELINE_CAPTIONS}`:
  1. 13:00「今日ミスった、しんどい」
  2. 18:00（夜ご飯の写真を何枚も撮り直す）
  3. 19:30「今日もがんばった自分えらい」投稿
  4. 23:00（自分の投稿を見返して真顔）
- `{PROP_ITEMS}`: スマホ（写真アプリの複数ショット・選択画面）、夜ご飯の皿の写真、いいね通知のアイコン

## プロンプト本文

```
YAKUMO（黒髪ツインお団子、ネオンピンクメッシュ、黒×ネオンピンクのサイバーゴシック衣装、
「89」の入ったヘッドフォン）とMONY（黒いウサギ型デバイス、＝ω＝の表情ディスプレイ）が
登場する、アニメ風デジタルイラストのコミック風アイキャッチ画像。

上部に大きく「しんどい日ほど元気アピールしてる人間」というタイトルテキスト（一部をネオンピンクで強調）。

中央に時系列パネル4コマ：
- 13:00「今日ミスった、しんどい」
- 18:00（夜ご飯の写真を何枚も撮り直している）
- 19:30「今日もがんばった自分えらい」投稿
- 23:00（自分の投稿を見返して真顔になっている）
各コマでYAKUMOの表情・状況が少しずつ変化していく（最初はぐったり、途中は無理に笑顔を作る、最後は真顔で画面を見つめる）。

右側に大きく「ブーメラン。」という文字と、いいね通知・スマホ写真アプリのアイコン。

左下にスマホの写真アプリ（複数ショットから1枚を選んでいる画面）、
夜ご飯の写真、いいね通知のアイコンを配置。

右下に「YAKUMO ω MONY」「TECH × LIFE × IDEAS × AI」のブランド表記。

配色は黒〜濃紫ベース＋ネオンピンクのハイライト、全体は少しダークで
サイバーパンクな雰囲気だが、YAKUMOとMONYの表情はどこか可愛らしく親しみやすい。
```
